¿Cómo abrir y probar el nivel?

El nivel se ejecutará desde Unreal Engine mediante el proyecto del videojuego, seleccionando el mapa principal y utilizando la opción de ejecución (Play). Para realizar las pruebas de realidad virtual se utilizará Meta XR Simulator, una herramienta que permite simular el funcionamiento de un visor y sus controles dentro del entorno de desarrollo, sin necesidad de conectar físicamente un dispositivo VR.

¿Cuáles son los controles?
   
Los controles se utilizarán mediante la simulación de los mandos de realidad virtual proporcionada por Meta XR Simulator, permitiendo comprobar las acciones que puede realizar el jugador.
| Control | Funcionalidad |
|---------|---------------|
| Joystick izquierdo | Desplazamiento del jugador. |
| Joystick derecho | Giro de la cámara o del jugador. |
| Gatillo derecho | Agarrar, sujetar y utilizar objetos. |
| Gatillo izquierdo | Interactuar con determinados elementos. |

¿Cómo comprobar que los controles funcionan?

Se realizarán pruebas individuales mediante Meta XR Simulator para verificar que cada control responda correctamente. Se comprobará el desplazamiento, la rotación, el movimiento de las manos, la manipulación de objetos, la activación de mecanismos y la resolución de acertijos.
Una vez verificadas las funciones individuales, se integrarán todas las ramas de programación en una rama principal, desde la cual se ejecutarán conjuntamente para comprobar que trabajen de manera correcta y coordinada.
